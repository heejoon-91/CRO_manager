# CRO 실험 관리 프로그램 v0.1

시험 기본정보, 군·개체, 체중, 임상증상, SOP 문서 체크리스트, 변경이력을 관리하는 사내용 웹 프로그램입니다.
PC 한 대에 설치해 두면 같은 사내망의 다른 PC에서는 브라우저로 접속합니다.

## 설치와 실행 (Windows)

1. Python 3.10 이상을 설치합니다. 설치 화면에서 **Add python.exe to PATH**를 체크합니다.
2. 이 폴더를 원하는 위치에 풉니다. 예: `D:\cro_manager`
3. `run.bat`을 더블클릭합니다. 처음 한 번은 필요한 패키지를 내려받으므로 인터넷 연결이 필요합니다.
4. 브라우저에서 `http://localhost:8000`을 엽니다. 다른 PC에서는 `http://<설치한 PC의 IP>:8000`으로 접속합니다.
   - 다른 PC에서 안 열리면 Windows 방화벽에서 8000번 포트를 허용해야 합니다.
5. 처음 접속하면 관리자 계정을 만드는 화면이 나옵니다.

macOS·Linux는 `./run.sh`로 실행합니다. 포트는 환경변수 `CRO_PORT`, 자료 폴더는 `CRO_DATA_DIR`로 바꿀 수 있습니다.

## 사용 순서

1. **사용자** 메뉴에서 직원 계정을 만듭니다. 기록에 이름이 남으므로 1인 1계정으로 씁니다.
2. **문서 종류** 메뉴에서 회사 SOP의 관리 문서 목록으로 바꿉니다. 초기 목록은 예시입니다.
   - **SOP 파일 올리기**를 누르고 회사 SOP(HWPX·HWP·PDF)를 올리면 SOP에 정의된 서식 목록을 찾아 보여줍니다. 단계·필수·연계를 확인하고 고친 뒤 체크한 서식만 등록합니다.
   - 시험마다 쓰지 않는 기관 공통 서식(SOP 관리대장, 교육훈련 계획 등)은 처음부터 체크가 빠져 있습니다. 단계는 서식 이름으로 짐작한 것이므로 꼭 확인하세요.
   - 등록한 뒤에는 필요 없는 예시 문서 종류를 '중지'로 바꿉니다.
3. **시험 등록**: 시험번호, 실험제목, 동물종, 마리수, 기간을 입력합니다. 문서 체크리스트가 자동으로 만들어집니다.
4. **군 · 개체**: 군 이름(G1, C1 등), 군 성격(음성 대조군·양성 대조군·실험군 또는 직접 입력), 설명과 개체마다 번호·성별·초기 체중(선택)을 입력하면 개체가 함께 만들어집니다. 초기 체중은 위의 "체중 측정일" 날짜로 체중 기록에 저장됩니다. 성별은 등록 뒤에도 개체 목록에서 개체별로 바꿀 수 있습니다(변경이력에 남음).
   - 군 이름을 한 번 적고, 오른쪽 개체 칸에 번호를 숫자로 하나씩 넣습니다. **+ 개체 추가**(또는 번호 칸에서 Enter)로 같은 군에 개체 칸을 더하면 다음 번호가 미리 채워집니다. 다른 군은 **+ 군 추가**로 넣습니다.
   - 개체번호는 G1-1, G1-2 … 처럼 '군 이름-번호'로 만들어집니다. 한 군이라도 틀리면 아무것도 등록하지 않고 틀린 곳을 표시합니다.
   - 이미 만든 군에는 아래 '기존 군에 개체 추가'에서 `11` 또는 `11-15`처럼 번호를 넣어 더합니다.
   - 군 이름은 개체번호에 들어가므로 공백과 '-' 없이 쓰고, 만든 뒤에는 바꿀 수 없습니다. 성격과 설명은 '군 정보 수정'에서 바꿉니다.
5. **체중 / 임상증상**: 날짜를 고르고 입력합니다. 군별 평균 ± SD와 그래프가 자동 계산되고, CSV로 내보내 엑셀에서 열 수 있습니다.
6. **문서**: 문서별 상태·문서번호·작성일·담당자·파일을 관리합니다.
   - 시험 전·중·후 칸은 제목을 눌러 접고 펼칩니다(모두 펼치기·접기). 접은 상태는 PC 브라우저에 기억됩니다. 위쪽 검색칸에 문서명·서식 번호·문서번호 일부를 입력하면 맞는 문서만 보입니다(Esc로 지우기).
   - 한 문서에 파일을 여러 개 올릴 수 있습니다(여러 개 한꺼번에 선택 가능, 파일 메모 입력 가능).
   - '미작성' 문서에 파일을 올리면 상태가 자동으로 '작성중'으로 바뀝니다(변경이력에 남음). 상태를 직접 고르고 올리면 고른 상태를 따릅니다.
   - 잘못 올린 파일은 사유를 적고 숨깁니다. 숨긴 파일도 지워지지 않고 '숨긴 파일'에서 내려받을 수 있습니다.
7. 시험이 끝나면 상태를 **종료**로 바꿉니다. 이후 체중·임상증상·개체 자료는 잠깁니다. 문서와 파일은 종료 후에도 계속 갱신할 수 있습니다.

## 기록 관리 규칙

- 이미 저장된 체중·임상증상을 고치거나 지우려면 변경 사유를 입력해야 합니다.
- 모든 입력·수정·삭제는 변경이력에 사용자, 시각, 이전 값, 새 값, 사유와 함께 남습니다. 이력은 프로그램에서 수정·삭제할 수 없습니다.
- 미래 날짜로는 기록할 수 없습니다.
- 기록이 있는 개체는 삭제할 수 없고, 상태를 폐사 또는 제외로 바꿉니다.
- 문서 파일은 덮어쓰지 않고 목록에 쌓이며, 숨긴 파일도 서버에 남습니다.

## 백업

모든 자료는 `data` 폴더에 있습니다(`cro.db`, `uploads`, `secret.key`).
이 폴더를 주기적으로 다른 저장장치에 복사하세요. 관리자 메뉴의 **DB 백업**은 `cro.db`만 내려받고 첨부 파일은 포함하지 않습니다.
프로그램을 새 버전으로 바꿀 때는 `data` 폴더만 남기고 나머지 파일을 교체합니다.

## 다른 PC로 옮기기

1. 기존 PC에서 서버 창을 닫아 서버를 끈 뒤 폴더 전체를 복사합니다(켜 둔 채 복사하면 DB가 깨질 수 있습니다).
2. 새 PC에 Python 3.10 이상을 설치합니다("Add python.exe to PATH" 체크).
3. `run.bat`을 실행합니다. `.venv`는 만든 PC에서만 동작하므로 처음 한 번 자동으로 다시 만들고 패키지를 설치합니다(인터넷 필요). `.venv`는 빼고 복사해도 됩니다.
4. Windows 방화벽 창이 뜨면 "개인 네트워크" 허용을 누릅니다.
5. 서버 주소(IP)가 바뀌므로 직원들에게 새 주소 `http://새PC의IP:8000`을 알려 줍니다. IP 확인 방법은 아래와 같습니다.

### 서버 PC의 IP 주소 확인하기

**방법 1. 명령 프롬프트**
1. `Win + R`을 누르고 `cmd`를 입력한 뒤 Enter를 누릅니다.
2. 검은 창에 `ipconfig`를 입력하고 Enter를 누릅니다.
3. 연결된 어댑터의 **IPv4 주소**를 봅니다. 유선이면 "이더넷 어댑터", 무선이면 "무선 LAN 어댑터 Wi-Fi" 항목입니다.
   ```
   이더넷 어댑터 이더넷:
      IPv4 주소 . . . . . . . . . : 192.168.0.25   ← 이 숫자
   ```
4. 직원들은 `http://192.168.0.25:8000`처럼 접속합니다.

**방법 2. 설정 화면**
`설정 → 네트워크 및 인터넷 → (이더넷 또는 Wi-Fi) → 연결된 네트워크 이름` 화면 아래쪽의 **IPv4 주소**를 봅니다.

**참고**
- `127.0.0.1`과 `169.254.`로 시작하는 주소는 다른 PC에서 접속할 수 없는 주소입니다. 보통 `192.168.`, `10.`, `172.`로 시작하는 주소를 씁니다.
- VMware나 VirtualBox 같은 가상 어댑터가 여러 개 보이면, 실제 사내망에 연결된 이더넷 또는 Wi-Fi 항목의 주소를 씁니다.
- 공유기가 PC를 켤 때마다 IP를 새로 줄 수 있어서, 재부팅하면 주소가 바뀔 수 있습니다. 바뀌지 않게 하려면 전산 담당자나 공유기 관리 화면에서 서버 PC에 **고정 IP(DHCP 예약)**를 설정해 달라고 요청하세요.
- 확인한 주소로 서버 PC에서도 `http://그IP:8000`이 열리는지 먼저 확인한 뒤 직원들에게 알려 주세요.

## 현재 한계

- 임상증상은 개체당 하루 1건만 기록됩니다.
- 통계는 군별 n, 평균, SD까지입니다. 군 간 유의성 검정은 없습니다.
- SOP 가져오기는 서식 번호(기본 `KULF/COM/001-1` 형식)로 서식을 찾습니다. 번호 체계가 다른 SOP는 올리기 화면의 '서식 번호 형식'을 바꿔야 합니다. 스캔한 이미지 PDF와 배포용(읽기 전용) HWP는 읽지 못합니다.
- SOP 가져오기의 단계 자동 분류는 컬프 공통 SOP(`sop_hints.json`)에 맞춰져 있고, 그 밖의 서식은 이름의 낱말로 짐작합니다.
- 통신이 암호화되지 않으므로(HTTP) 사내망에서만 쓰고 외부 인터넷에 노출하지 마세요.
- 전자서명, 접근 기록 등 GLP 수준의 전산시스템 요건은 충족하지 않습니다.
